Predict Athlete Prediction

A machine learning web application that analyses a user's physical attributes to predict their most suitable playing position. Built with a dataset of over 18,000 football players and presented at UWI FST Open Day 2025 to demonstrate ML-driven player evaluation.

My Role

Team Lead | Data Scientist | Full-Stack Developer

  • Led a team of 3 developers, overseeing task delegation, sprint planning, and regular reporting using Agile methodology and Trello for tracking progress and accountability.

  • Implemented an algorithm to scrape nationality data from a third-party football website using Selenium and BeautifulSoup, enriching our dataset of 18,000+ players.

  • Developed a 15-binary classifier system using Random Forest and XGBoost, applying SMOTE oversampling, PCA, RFE, and Lasso to refine 52 input features per position.

  • Created an interactive Leaflet.js map to explore league-wise stats like nationality distribution, career length, and average age.

Key Features

Position Prediction

Predict the most suitable position for an athlete based on the user inputted physical attributes.

Similar Player Finder

Displays the top 5 most similar players based on the user inputted physical attributes.

Web Application

Users interact with the ML model through a clean web interface, input physical attributes and receive instant predictions.

Data Collection

Dataset of 18,000+ players sourced from kaggle and enriched with scraped nationality data using Selenium and BeautifulSoup.

Data Pre-processing

Clean and prepare the dataset for model training using pandas. SMOTE oversampling to handle class imbalance. Feature selection using PCA, RFE and Lasso to reduce 52 input features.

Machine Learning Model

15-binary classifier system, one classifier per position where the best confidence wins. Random Forest and XGBoost models compared, best performer selected per position.

What the Project Achieved

The project successfully delivered a working prediction system capable of recommending the most suitable playing position for an aspiring footballer based on their physical attributes. Beyond the model itself, the project was delivered as a full-stack web application built with Flask, allowing users to input their attributes and receive real-time position predictions alongside the 5 most physically similar professional players from the dataset. The project was presented at the University of the West Indies open day and a technical paper was co-authored in IEEE format, demonstrating both the academic rigour and practical application of the work.

Limitations

While the project achieved its core objectives, several limitations were identified. The dataset was heavily skewed towards European leagues, resulting in limited representation of players from other regions and reducing the system's ability to generalise across a more diverse global football landscape.


The dataset also contained no data for women athletes, meaning the prediction system is limited to male professional players only, a significant gap given the growth of women's football worldwide.


Lower league players were under-represented, as most data was sourced from higher-profile leagues. This means predictions may be less reliable for users whose attributes align more closely with lower-league football.


The physical attribute inputs lacked real-world context for the average user. Without a clear benchmark or reference point, a user inputting a value such as their sprint speed or agility score may not know what constitutes a good, average, or poor value, potentially affecting the quality of predictions made.

Future Improvements

The most impactful improvement would be expanding the dataset to include broader global representation, incorporating more players from South American, African, and Asian leagues to significantly improve the model's ability to generalise across different playing styles and physical profiles.


Including women athletes in the dataset would be a meaningful extension of the project, allowing the system to serve a much wider audience and reflect the growing prominence of women's football at both professional and grassroots levels.


A key improvement would be establishing real-world context for the physical attribute values used in the dataset. The data uses arbitrary numerical scores, for example, a sprint speed of 80 or 90, but provides no indication of what these numbers actually represent in measurable, real-world terms such as kilometres per hour. Mapping these scores to recognised athletic benchmarks would make the inputs far more meaningful, both for users entering their attributes and for interpreting what the model has actually learned from the data.
